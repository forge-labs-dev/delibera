# Delibera Documentation

This directory contains the design documentation for Delibera, an engine for decision-grade AI deliberation.

## Reading Order

Start here and follow in order:

1. **[Vision](vision.md)** — What Delibera is, why it exists, and its design principles
2. **[Formalism](formalism.md)** — Formal model and terminology (the canonical reference)
3. **[Architecture](architecture.md)** — Software architecture and module boundaries
4. **[Protocols](protocol.md)** — How deliberation protocols are specified and executed
5. **[Epistemics](epistemics.md)** — Claims, evidence, objections, and validation
6. **[Tooling and Policy](tooling-and-policy.md)** — External tool integration and policy enforcement
7. **[Tracing and Replay](tracing-and-replay.md)** — Execution recording and deterministic replay
8. **[User Gates](user-gates.md)** — Structured human-in-the-loop interaction
